# WorshipChord

สมุดเพลงนมัสการแบบเว็บแอปสำหรับ iOS, Android, iPad และมือถือ ใช้ HTML/CSS/JavaScript ฝั่งหน้าเว็บ กับ Node.js, MongoDB Atlas และ WebSocket สำหรับกลุ่มเพลง

## เปิดใช้งานบนเครื่องนี้

ต้องใช้ Node.js 20 ขึ้นไป

```powershell
npm install
npm start
```

เปิด [http://127.0.0.1:8000](http://127.0.0.1:8000) การสมัครและซิงก์ข้ามอุปกรณ์ต้องเชื่อม MongoDB Atlas ก่อน IndexedDB เก็บแคชแยกตามบัญชี และเปิดให้แก้เพลงส่วนตัว/เพลงวันนี้เมื่อ API หรือเครือข่ายขาดการเชื่อมต่อ จากนั้นคิวจะซิงก์เมื่อกลับมาออนไลน์

## เปิดใช้บัญชีและกลุ่มเพลง

1. สร้างคลัสเตอร์ MongoDB Atlas และ database user แล้วกำหนด network access ให้เซิร์ฟเวอร์ Node.js เชื่อมต่อได้
2. คัดลอก `.env.example` เป็น `.env`
3. ตั้ง `MONGODB_URI` เป็น connection string ของ Atlas, `MONGODB_DB` เป็นชื่อฐานข้อมูล และตั้ง `SESSION_SECRET` เป็นค่าสุ่มยาวอย่างน้อย 32 ตัวอักษร
4. รัน `npm start` ใหม่ แล้วสมัคร/เข้าสู่ระบบจากปุ่มมุมขวาบน

อย่าส่งหรือ commit ไฟล์ `.env` ขึ้น Git. เมื่อไม่มี `MONGODB_URI` หน้าเว็บเปิดได้ แต่บัญชี เพลงส่วนตัว เพลงวันนี้ และกลุ่มจะยังใช้งานไม่ได้

ถ้าเบราว์เซอร์มีเพลงจากเวอร์ชันเก่าที่เก็บไว้ในเครื่อง ระบบจะถามก่อนนำเข้าเพลงเหล่านั้นไปยังบัญชีที่กำลังเข้าสู่ระบบ

## เปิดจากมือถือในเครือข่ายเดียวกัน

บนเครื่องที่รัน Node.js ตั้ง `HOST=0.0.0.0` ใน `.env` แล้วเปิดพอร์ต 8000 ใน firewall ของเครือข่ายส่วนตัว จาก iPad/มือถือเข้า `http://<IP-ของเครื่องที่รันแอป>:8000` ได้ โหมดนี้มีไว้ทดลองบน Wi-Fi เดียวกัน; การเผยแพร่สู่ภายนอกและติดตั้ง PWA ควรใช้ HTTPS และไม่ควรเปิด MongoDB ให้เข้าถึงสาธารณะ

## การใช้งาน

- เพิ่มและแก้เพลงด้วยการพิมพ์หรือวางเนื้อร้องกับคอร์ดในช่องข้อความ
- เปิดคอร์ดในรูปแบบ `[G]` หรือแถวคอร์ดล้วน, เปลี่ยนคีย์และกลับคีย์ต้นฉบับได้
- เพลงส่วนตัวและ “เพลงวันนี้” เก็บใน MongoDB โดยแยก `ownerId` ตามบัญชี จึงซิงก์ข้ามอุปกรณ์ และผู้ใช้อื่นจะอ่านข้อมูลนี้ไม่ได้
- IndexedDB เก็บแคชและคิวซิงก์แยกตามบัญชี; เมื่อออฟไลน์แก้เพลงส่วนตัวและเพลงวันนี้ได้ ส่วนกลุ่ม/คำเชิญต้องออนไลน์
- แตะเพลงเพื่อเปิดหน้าอ่านคอร์ด ดูตำแหน่งปัจจุบัน/เพลงถัดไป และเลือกเพลงจากรายการด้านข้างบนจอใหญ่; บนมือถือแตะปุ่ม “เพลงในชุด” เพื่อเปิดรายการ
- เปลี่ยนลำดับเพลงในคลัง/เพลงวันนี้ และลากเพลงเข้ารายการวันนี้บนอุปกรณ์ที่รองรับ drag-and-drop; มีปุ่มลูกศรเป็นทางเลือกบนจอสัมผัส
- สมัครบัญชีเพื่อสร้างกลุ่ม ค้นหาสมาชิกด้วยชื่อหรือ public ID แล้วส่งคำเชิญ กำหนดสิทธิ์ดูหรือแก้ไข และแก้เพลง/ลำดับกลุ่มร่วมกัน; อีเมลบัญชีต้องไม่ซ้ำ ส่วนชื่อแสดงซ้ำได้
- หลังสมัครให้บันทึก recovery code ที่แสดงครั้งเดียว; ใช้ code นี้ตั้งรหัสผ่านใหม่ได้โดยไม่ต้องใช้อีเมลยืนยัน
- ระบบตรวจเพลงซ้ำในเพลงของฉัน, เพลงวันนี้ และแต่ละกลุ่ม โดยเทียบชื่อเพลงกับศิลปิน; เพลงในคลังส่วนตัวเพิ่มเข้าเพลงวันนี้ได้ แต่เพิ่มชื่อ/ศิลปินเดิมซ้ำภายในรายการเดียวกันไม่ได้
- Owner/editor ลากเพลงจากคลังส่วนตัวเข้ากลุ่มได้ (มือถือใช้ปุ่มแชร์) และเปลี่ยนคีย์แสดงผลของเพลงกลุ่มให้สมาชิกเห็นแบบเรียลไทม์ โดยยังเก็บคีย์ต้นฉบับไว้
- สมาชิกกลุ่มคัดลอกเพลงมาไว้ในคลังส่วนตัวได้ด้วยปุ่มหรือการลาก สำเนาใช้คีย์ที่กลุ่มกำลังแสดงและแก้ไขแยกจากต้นฉบับได้
- กลุ่มอัปเดตสดเมื่อหน้าเว็บเปิดอยู่; คำเชิญและการตอบรับเก็บในกล่องแจ้งเตือนเพื่อเปิดย้อนหลังได้ ไม่มีแจ้งเตือนระบบปฏิบัติการเมื่อปิดเว็บ
- สำรอง/นำเข้า JSON สำหรับเพลงส่วนตัวและเพลงวันนี้; เพลงกลุ่มแยกเก็บใน Atlas ตามสิทธิ์กลุ่ม

## ข้อจำกัด

- การสมัคร ซิงก์ข้ามอุปกรณ์ และกลุ่มต้องมี Node.js server กับ MongoDB Atlas ที่ออนไลน์; การแก้ส่วนตัว/เพลงวันนี้ออฟไลน์ได้เฉพาะอุปกรณ์ที่มีแคชบัญชีนั้น และจะซิงก์ภายหลัง
- โค้ดนี้ไม่ส่งอีเมลเอง: ผู้รับที่ยังไม่มีบัญชีต้องสมัครด้วยอีเมลที่เจ้าของเชิญก่อน แล้วจึงเห็นคำเชิญในกล่องแจ้งเตือน
- แผนฟรีของโฮสต์หรือ MongoDB มีข้อจำกัดและเงื่อนไขของผู้ให้บริการ อาจเปลี่ยนได้; ค่าใช้จ่ายจริงขึ้นกับการเลือก deploy, traffic และการตั้งค่าบัญชี
- ระบบยังไม่ได้ยืนยันอีเมลด้วยอีเมลยืนยันตัวตน ควรใช้กับทีมที่รู้จักกันก่อนนำเพลง/ข้อมูลที่จำกัดสิทธิ์ไปแชร์
- รุ่นนี้ยังไม่รองรับการค้นหาหรือเล่น YouTube, นำเข้าจากลิงก์หน้าเว็บคอร์ด หรืออ่านคอร์ดจากรูป; ให้พิมพ์หรือวางข้อความคอร์ดเอง
- ลิงก์ YouTube/เว็บคอร์ดที่บันทึกไว้จากรุ่นก่อนยังคงอยู่ในข้อมูลและไฟล์สำรอง แต่รุ่นนี้ไม่แสดงหรือใช้งานลิงก์เหล่านั้น

การตัดสินใจและแบบจำลองข้อมูลอยู่ใน [เอกสารออกแบบ](docs/README.md)
